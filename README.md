# Mall Customer Segmentation - EDA & Visual Insights

**Exploratory Data Analysis** on the famous **Mall Customers** dataset to understand customer behavior and spending patterns.

---

## 📊 Project Overview

This project performs comprehensive Exploratory Data Analysis on customer demographics, annual income, and spending scores. The goal is to uncover meaningful insights for customer segmentation and targeted marketing strategies.

### Features:
- Age, Gender, Annual Income, Spending Score
- Correlation Analysis
- Distribution Plots
- Relationship Analysis
- Data Preprocessing & Scaling

---

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

---

## 📈 Key Insights

- Strong correlation between **Annual Income** and **Spending Score**
- Different customer clusters visible in Income vs Spending plot
- Age-wise spending behavior analysis
- Gender-based spending patterns
